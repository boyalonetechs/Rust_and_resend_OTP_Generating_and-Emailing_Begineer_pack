# Rust and Resend Otp Emailing Starter Pack

---
## Steps

- Clone the repo
```
https://github.com/boyalonetechs/Rust_and_resend_OTP_Generating_and-Emailing_Begineer_pack.git
```

- create a resend account, connect your domain and create an api key pase it in this line
```
 line 22:   let resend = Resend::new("resend_api");
```

- Then run cargo
```
cargo run
```
